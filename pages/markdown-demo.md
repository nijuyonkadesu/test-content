# Markdown Demo

This page exercises the Phase 7 Markdown foundations: frontmatter, heading
anchors, and footnotes.

## Headings have copy links

Hover any heading and a `#` appears — click it to copy a deep link to that
section.[^anchor]

## Footnotes render as superscripts

The lab invented the PhoneWave[^1], a device that sends mail to the past.
Time travel has consequences.[^2]

## Frontmatter is hidden

The YAML block at the top sets `title` and `categories` but is not rendered
in the page body.

[^anchor]: The link is copied to your clipboard and the URL hash updates.
[^1]: Technically a microwave that had been heavily modified.
[^2]: See the divergence meter for details.
