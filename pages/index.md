# Welcome to the Steins;Gate Wiki

The lab-member-maintained encyclopedia about the Future Gadget Laboratory,
worldlines, and everyone caught in between. This demo runs on **Fwiki** — the
content you're reading is plain markdown in a git repo, and every edit ships
as a pull request.

**Contribute**

Anyone can help. Hit **Edit**, make your change, and **Publish** — it opens a
pull request for review. Red links are pages nobody has written yet: claim one!

::section[How this wiki works]{icon="⚙️"}

Pages live as markdown files; branches are drafts; pull requests are the
moderation queue. `Ctrl+S` saves to your personal draft, `Ctrl+K` searches,
and the book icon in the toolbar opens the syntax guide.
